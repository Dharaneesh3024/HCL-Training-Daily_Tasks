# Car Rental Management System

## 📌 Overview

The **Car Rental Management System** is a backend application designed to manage the core operations of a car rental business.

The system aims to provide a centralized platform for managing vehicles, customers, rentals, availability, vehicle maintenance, and rental charges. It is being developed as a **Java Spring Boot REST API** following a layered architecture.

## 🎯 Project Objectives

- Manage branches and rental vehicles
- Search for available vehicles based on rental periods
- Manage customer rental bookings
- Record vehicle pickup and return details
- Calculate rental and additional charges
- Manage vehicles blocked for maintenance
- Track vehicle utilization

## 🛠️ Technologies

- **Java 21**
- **Spring Boot**
- **Spring Web**
- **Maven**
- **REST APIs**
- **Git & GitHub**
- **Postman**

## 🏗️ Planned Architecture

The application follows a layered backend architecture:

```text
Client
   ↓
Controller
   ↓
Service
   ↓
Data / Model Layer
```

The project will also include centralized exception handling and DTOs as the application evolves.

## 📂 Project Scope

The system is being developed incrementally, with features and components added throughout the development process.

The primary focus is to build a maintainable and scalable backend while applying Java, Spring Boot, REST API, exception handling, and software development practices.
