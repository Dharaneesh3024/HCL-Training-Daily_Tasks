\# Day 3 - Control Flow and Maven



\## Objective



Understand Java control flow concepts and learn the fundamentals of Maven-based project management.



\## Topics Covered



\- Conditional statements using if-else

\- switch statements

\- while loops

\- do-while loops

\- Enhanced for-each loops

\- break and continue statements

\- Input validation

\- Maven project structure

\- pom.xml configuration

\- Maven build lifecycle

\- Maven profiles



\## ATM Simulator



The ATM Simulator is a console-based Java application that demonstrates:



\- PIN-based user authentication

\- Limiting PIN entry to three attempts

\- Menu-driven operations using switch

\- Checking account balance

\- Depositing money

\- Withdrawing money

\- Displaying a mini transaction statement

\- Validating user input

\- Repeating menu operations using a do-while loop

\- Iterating through transactions using a for-each loop

\- Using break and continue for flow control
