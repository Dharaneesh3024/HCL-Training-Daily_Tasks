# Day 2 - Java Language Fundamentals

## Objective

Learn the fundamentals of the Java programming language and basic Git concepts by developing a Monthly Usage Analyzer program.

## Topics Covered

- Primitive data types
- Variables and constants
- Arrays
- Operators
- Type casting
- Widening conversion
- Narrowing conversion
- Integer overflow
- Floating-point precision
- Two-dimensional arrays
- Git fundamentals

## Monthly Usage Analyzer

The program uses an integer array to store usage values for 12 months.

It performs the following operations:

- Calculates total usage
- Finds the average usage
- Identifies the minimum usage
- Identifies the maximum usage

## Constants

Application-related constant values are maintained separately in a `Constants` class.

The following constants are used:

- `Constants.MONTHS`
- `Constants.HOUSES`
- `Constants.DAYS_IN_WEEK`
